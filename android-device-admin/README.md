# Hi3516 Android 设备管理员应用

这是一个运行在 Android 13 上的设备管理员应用，用于管理和保护 Hi3516 平台相关的 Android 设备。

## 功能特性

### 设备安全功能
- **设备锁定**: 立即锁定设备屏幕
- **密码策略**: 设置数字密码，最少 6 位
- **锁屏超时**: 自动锁屏时间控制（默认 1 分钟）
- **相机控制**: 启用/禁用设备相机

### 数据管理
- **远程擦除**: 擦除设备上的所有数据（需要谨慎使用）

### 安全监控
- **密码尝试监控**: 跟踪失败的密码尝试
- **安全通知**: 通过通知系统提醒安全事件
- **登录监控**: 监控设备登录和解锁事件

## 系统要求

- **最低 SDK**: Android 13 (API 33)
- **目标 SDK**: Android 13 (API 33)
- **Java 版本**: Java 8 或更高

## 构建说明

### 前置条件
1. 安装 Android Studio 或 Android SDK
2. 安装 JDK 8 或更高版本
3. 配置 ANDROID_HOME 环境变量

### 构建步骤

```bash
# 进入 Android 应用目录
cd android-device-admin

# 使用 Gradle 构建（如果已安装 Gradle）
./gradlew assembleDebug

# 或使用 Android Studio
# 1. 在 Android Studio 中打开项目
# 2. 选择 Build -> Build Bundle(s) / APK(s) -> Build APK(s)
```

### 生成 APK

构建完成后，APK 文件位于：
```
app/build/outputs/apk/debug/app-debug.apk
```

## 安装说明

### 通过 ADB 安装

```bash
# 启用设备的 USB 调试模式
# 连接设备到电脑

# 安装 APK
adb install app/build/outputs/apk/debug/app-debug.apk

# 激活设备管理员
# 方法 1: 使用应用界面
adb shell am start -n com.hi3516.deviceadmin/.MainActivity

# 方法 2: 通过系统设置
# 设置 -> 安全 -> 设备管理应用 -> Hi3516 设备管理员
```

### 手动安装

1. 将 APK 文件复制到设备
2. 在设备上打开 APK 文件
3. 允许安装未知来源应用
4. 完成安装

## 使用指南

### 激活设备管理员

1. 打开 "Hi3516 设备管理员" 应用
2. 点击 "激活设备管理员" 按钮
3. 在系统提示中确认激活
4. 返回应用，状态应显示 "设备管理员已激活"

### 使用设备控制功能

激活设备管理员后，可以使用以下功能：

1. **锁定设备**: 点击按钮立即锁定设备屏幕
2. **设置密码策略**: 设置设备密码为 6 位数字
3. **设置锁屏超时**: 设备将在 1 分钟无操作后自动锁定
4. **禁用相机**: 禁用设备相机功能（可再次点击启用）

### 远程擦除数据

⚠️ **警告**: 此操作将删除设备上的所有数据，无法撤销！

1. 确保已激活设备管理员
2. 点击 "擦除数据" 按钮
3. 确认操作
4. 设备将恢复出厂设置

## 应用架构

### 主要组件

```
com.hi3516.deviceadmin/
├── MainActivity.java          # 主界面 Activity
└── receiver/
    ├── DeviceAdminReceiver.java    # 设备管理员接收器
    └── DeviceAdminHelper.java      # 辅助工具类
```

### 功能说明

- **MainActivity**: 提供用户界面，处理用户交互和设备管理操作
- **DeviceAdminReceiver**: 接收设备管理相关事件（启用、禁用、密码错误等）
- **DeviceAdminHelper**: 提供通知和其他辅助功能

## 权限说明

应用需要以下权限：

- `BIND_DEVICE_ADMIN`: 绑定设备管理员权限（必需）
- `USE_BIOMETRIC`: 使用生物识别
- `USE_FINGERPRINT`: 使用指纹识别
- `MANAGE_USB`: 管理 USB 设备
- `REBOOT`: 重启设备

## 安全注意事项

1. **激活前的确认**: 在激活设备管理员前，请确认了解所有功能的含义
2. **擦除数据警告**: 擦除数据操作不可逆，请谨慎使用
3. **密码策略**: 设置密码策略后，用户必须遵守新规则
4. **相机禁用**: 禁用相机可能影响某些应用功能
5. **卸载限制**: 设备管理员激活后，可能无法直接卸载应用

## 故障排除

### 无法激活设备管理员

**原因**: 可能已被其他设备管理员限制

**解决方案**:
1. 检查是否已有其他设备管理员应用
2. 检查设备是否由企业/学校管理
3. 尝试在设置中手动添加设备管理员

### 某些功能不可用

**原因**: 部分功能可能需要设备支持或特定权限

**解决方案**:
1. 确认设备硬件支持相关功能
2. 检查是否有其他应用限制
3. 查看 Android 系统日志获取更多信息

### 无法卸载应用

**原因**: 设备管理员应用需要先停用才能卸载

**解决方案**:
1. 在应用中点击 "停用设备管理员"
2. 或在设置中手动停用
3. 然后卸载应用

## 开发说明

### 修改应用包名

如需修改应用包名，请更新以下文件：

1. `app/build.gradle` - `applicationId`
2. `app/src/main/AndroidManifest.xml` - `package` 和所有组件的完整类名
3. 所有 Java 源文件的包声明

### 添加新功能

1. 在 `device_admin.xml` 中添加所需策略
2. 在 `MainActivity.java` 中添加用户界面和控制逻辑
3. 在 `DeviceAdminReceiver.java` 中添加事件处理

### 自定义界面

修改 `res/layout/activity_main.xml` 来自定义用户界面。
